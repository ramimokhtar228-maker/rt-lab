# RT LAB — تثبيت كتطبيق (PWA)

## مهم
يجب فتح البرنامج عبر **http:// أو https://** وليس كملف `file://`.

## على الموبايل (أندرويد)
1. افتح الرابط في **Chrome**
2. القائمة ⋮ → **تثبيت التطبيق** أو **إضافة إلى الشاشة الرئيسية**
3. أو اضغط بانر **تثبيت الآن** أسفل الشاشة

## على آيفون / آيباد
1. افتح الرابط في **Safari** فقط
2. زر المشاركة □↑ → **إضافة إلى الشاشة الرئيسية**

## على اللابتوب (Windows / Mac)
1. افتح الرابط في **Chrome** أو **Edge**
2. أيقونة التثبيت في شريط العنوان (⊕ أو شاشة الكمبيوتر)
3. أو القائمة → **تثبيت RT LAB**

## تشغيل محلي سريع (بدون استضافة)
من مجلد البرنامج:

```bash
# Python
python3 -m http.server 8080

# أو Node
npx --yes serve -p 8080
```

ثم افتح: http://localhost:8080

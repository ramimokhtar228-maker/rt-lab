# RT LAB — معامل رامي مختار
نظام إدارة معمل تحاليل (PWA)

## التحديث v9 — سير العمل + مالية + دفع

### ما تغيّر
- **الرئيسية**: مسار عمل واضح (قيد التسجيل → سحب → تحليل → إرسال)
- **الحالات** بدل «الطلبات» مع تدفق تلقائي بين المراحل
- **المواعيد**: بعد 24 ساعة يظهر إلغاء أو تأجيل (مش إلغاء صامت)
- **الدفع**: حماية ضد الرجوع لـ«غير مدفوع» بعد التحصيل
- **المالية**: يومي / شهري / سنوي + نصيب CEO والمعمل
- إخفاء: لوحة اليوم، قوالب واتساب، باركود العينات المنفصل (التدفق من مسار الحالة)

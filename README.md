# RT LAB — معامل رامي مختار
نظام إدارة معمل تحاليل (PWA)

## التشغيل
1. ارفع كل محتويات المجلد معاً على الاستضافة (GitHub Pages / أي سيرفر)
2. افتح الرابط https://...
3. للتثبيت كتطبيق: Chrome/Edge → تثبيت التطبيق

## محلياً
```bash
python3 -m http.server 8080
```
افتح http://localhost:8080

## ملاحظات
- البيانات تُحفظ محلياً في المتصفح (localStorage) + مزامنة سحابة اختيارية (Supabase)
- **تحديث مهم:** الحذف أصبح منطقياً (soft delete) — الطلبات/المرضى المحذوفة لا تعود من السحابة
- امسح الكاش بعد كل تحديث (Ctrl+F5 أو امسح بيانات الموقع)
- إذا امتلأت الذاكرة: من الإعدادات صدّر البيانات ثم استخدم «تفريغ مساحة الحفظ»

# RT LAB - معامل رامي مختار

تطبيق حجز التحاليل وإدارة المعمل (PWA)

## الملفات

- `index.html` → التطبيق الكامل
- `sw.js` → Service Worker (أوفلاين)
- `manifest.webmanifest` → إعدادات التثبيت
- `icon-192.png` / `icon-512.png` → الأيقونات

## الرفع على GitHub Pages

1. اعمل Repository جديد على GitHub (مثلاً اسمه `rt-lab`)
2. ارفع كل الملفات دي جوه الريبو
3. روح Settings → Pages
4. Source: Deploy from a branch → اختر `main` و `/ (root)`
5. استنى دقيقة وهيديك اللينك:
   `https://YOUR_USERNAME.github.io/rt-lab/`

## التثبيت على الموبايل

### أندرويد
- افتح اللينك من Chrome
- اضغط "تثبيت التطبيق" أو من القائمة ⋮ → تثبيت التطبيق

### آيفون
- افتح من Safari
- مشاركة → إضافة إلى الشاشة الرئيسية

## ملاحظات
- لازم يكون الموقع على HTTPS (GitHub Pages بيعمل كده تلقائي)
- بعد أي تعديل: ارفع الملفات تاني وعمل Hard Refresh
